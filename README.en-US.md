# Thousand Star Wonderland Toolbox

Thousand Star Wonderland Toolbox is an AI-powered collection of tools designed to enhance editing efficiency within the Thousand Star Sandbox.

## Features

- **Knowledge Q&A System**: Multi-turn dialogue based on RAG + Agent, supporting semantic retrieval and structured queries of official documentation, tutorials, FAQs, and community experiences.
- **Document Preprocessing & Derivation**: Using `process_docs.py` to aggregate and process raw documents, automatically generating node classification documents, FAQ aggregations, structured indexes (`index.json`), and 69+ SVG "One-Image Flow" infographics to provide high-quality input for Q&A and visualization.
- **Agent Mode**: A tool-calling engine based on LlamaIndex FunctionAgent, featuring 5 built-in tools (node query, document list, document retrieval, knowledge search, and chart generation), supporting streaming SSE and tool-call chain tracing.
- **SVG Chart Generation**: The Agent can automatically generate SVG charts (node relationships, execution flows, logical structures, etc.) within responses. These are converted to PNG via cairosvg for embedded display and support CJK Chinese font rendering.
- **SVG One-Image Flow Docs**: A visualization documentation browsing page (`/svg`) automatically generated from derived documents, supporting keyword search and dual-format output (SVG/PNG).
- **Skill + API Capability Layer**: The same set of Thousand Star knowledge query capabilities is exposed as both an MCP Server and an HTTP Skill API.
- **QQ Bot**: Q&A services provided via a nonebot plugin.

## Repository Strategy

- Frontend build artifacts (`index.html` and `assets/*` under `backend/static/`) are no longer committed to the repository.
- When deploying, you must perform the frontend build (`cd frontend && npm run build`) before restarting the backend service.
- The repository only stores source code and configurations to avoid massive hash file differences (delete/add) during each release.
